## بنية المستودع (كما وُجدت)

- `.gitignore` — قواعد الاستبعاد
- `01#` إلى `19#` — مجلدات رقمية فردية

لكل مجلد رقمي نتوقع أن يحتوي على ملفات المسائل وحلولها. إن رغبت، أستطيع استعرض محتويات أحد هذه المجلدات بالتفصيل.

## كيف أتنقل في المستودع؟
- ابدأ بفتح أي مجلد رقمي (مثال: `01#`) لتطلع على المسائل المرتبطة بتلك المجموعة.
- اسمح للمجلدات الاحتفاظ بتسميات واضحة للملفات: `NNN-عنوان-قصير.md` للمسألة و`NNN-عنوان-قصير-solution.md` للحل.
- إذا رغبت بقائمة مصفوفة (index) تربط لكل مسألة وحلها، أستطيع إنشاء ملف `INDEX.md` آليًا يقرأ كل المجلدات ويرتبها.

## قالب مقترح لكل ملف حلّ (تجنّب اختلاف الصيغ بين الملفات)
في كل ملف حل نوصي بهذا القالب لجعل القراءة سهلة وموحّدة:

- العنوان
- رقم المسألة
- المستوى: مبتدئ / متوسط / متقدّم / غير مُسجّل
- الوصف (نص المسألة)
- الفكرة الأساسية للحل
- كود الحل (مُعلّق)
- أمثلة إدخال/مخرَج
- تعقيد: الزمن والذاكرة
- ملاحظات وحالات حافة

مثال بداية ملف حل:

```
# 012 - جمع عناصر القائمة
المستوى: مبتدئ

## الوصف
...
```
