## كيف تُقرأ الحلول
لكل حل نوصي بتضمين العناصر التالية في رأس ملف الحل:
- العنوان  
- رقم المسألة (إن وُجد)  
- المستوى: مبتدئ / متوسط / متقدّم / غير مُسجّل  
- فكرة الحل (موجزة)  
- الخوارزمية أو الكود (مع تعليقات توضيحية)  
- أمثلة إدخال/مخرَج  
- تحليل التعقيد (زمن/ذاكرة)  
- حالات الحافة والملاحظات التحسينية

مثال سريع لهيكل ملف حل:
```markdown
# 012 - عنوان المسألة
المستوى: متوسط

## الوصف
(نص المسألة...)

## الفكرة
(شرح مختصر...)

## الحل (كود)
```python
# كود الحل هنا
```

## أمثلة
Input: ...
Output: ...

## تعقيد
Time: O(...)
Space: O(...)
```
